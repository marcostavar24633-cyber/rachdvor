# Рачный двор

Сайт-каталог варёных раков с карточками товаров, корзиной-заявкой и административной частью.

## Дизайн-концепция: Coastal Nocturne

Кинематографическая гастрономическая подача: полноэкранный Hero, затемнённая фотография с мягким движением камеры, глубокие природные зелёно-графитовые оттенки и тёплый янтарно-медный акцент. Композиция строится на крупных заголовках, выразительной типографике и чередовании визуальных сцен.

Рассматривались три направления:
1. **Coastal Nocturne** — тёмная атмосферная гастрономическая эстетика.
2. **Market Editorial** — светлая журнальная верстка с акцентом на типографику.
3. **Rustic Table** — натуральная ремесленная подача с тёплыми текстурами.

Выбрано Coastal Nocturne: оно поддерживает премиальную подачу продукта и существующую тёмную айдентику, усиливая первый экран и цельность страниц.

## Страницы
- `index.html` — главная, динамический каталог, корзина и заявка.
- `catalog.html` — поиск и фильтрация ассортимента.
- `product.html` — карточка товара и запрос продавцу.
- `admin-login.html` — вход администратора.
- `admin.html` — редактирование каталога.
- `admin-orders.html` — управление заявками.
- `data.json` — резервные исходные данные.

## Источник каталога

Главная страница загружает каталог из `GET /api/catalog`, как и каталог с карточками товаров. При недоступности API главная, каталог и карточка товара используют `data.json` как резерв. На статическом хостинге GitHub Pages это позволяет просматривать ассортимент без Pages Functions; серверные операции (заявки и администрирование) требуют среды, поддерживающей Cloudflare Pages Functions. Сохранённые администратором изменения отображаются на публичных страницах после обновления. API нормализует поля товара, включая размер/калибр и состав; эти характеристики доступны для редактирования в панели.

## Серверные настройки

Для полноценной работы Pages Functions нужны KV binding `ORDERS_KV`, секрет `ADMIN_PASSWORD`, секрет `SESSION_SECRET` длиной не менее 32 символов. Для Telegram-уведомлений нужны `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Секреты нельзя размещать в клиентских HTML/JS-файлах.

## Работа с GitHub и публикация

Разработка ведётся в GitHub. Публикация на Cloudflare не выполняется без отдельного разрешения. Workflow `.github/workflows/unpack-site.yml` распаковывает ZIP в репозиторий и не является Cloudflare-деплоем.

## Перед запуском

Заменить демонстрационные фотографии фактическими изображениями товара, подтвердить ассортимент, цены, город, доставку, оплату и контакты продавца. Проверить KV, авторизацию администратора, Telegram и сценарии заявок на целевой среде.
